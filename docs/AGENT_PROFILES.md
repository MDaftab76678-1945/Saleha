## Adopting Agent Personas

### In CLI:
```powershell
# Adopt specific persona for a task
saleha run "Implement distributed Raft consensus node" -p sde
saleha run "Audit JWT auth handler" -p security_engineer
```

### In VS Code Studio:
Select the persona from the dropdown menu in the Saleha Sidebar Studio.
