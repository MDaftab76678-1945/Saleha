6 Core Superpowers Built In

Saleha v2.6.0 delivers everything professional engineering teams require — fully integrated into one clean CLI and web dashboard.

🩹

Autonomous Self-Healing Loop

Runs your failing test suite, localizes root-cause errors via AST diagnostics, patches code surgically, and validates fixes in real isolated sandboxes.

saleha fix "pytest"
🔍

AI Deep Code Reviewer

Scans for OWASP Top-10 vulnerabilities (SQLi, Shell injection, hardcoded tokens, weak crypto) and generates responsive HTML severity heatmaps.

saleha review-ai . --html
🧠

Per-Project Episodic Memory

Never forgets architectural decisions, tricky bug fixes, or library conventions across sessions using local persistent vector & SQLite stores.

saleha memory-project --recall
🚀

Local LoRA Fine-Tuning

Harvests high-quality solution pairs from your successful engineering sessions to train and adapt local Ollama models with zero cloud fine-tuning bills.

saleha tune --model qwen2.5
✂️

Surgical Diff & Blast Radius

Estimates codebase impact before applying any change. Computes 1–10 risk scores, hunk breakdown, and AST caller dependencies with rollback safety.

saleha diff-preview old.py new.py
👀

Real-Time Watch-AI Suggester

Monitors file saves in the background (<20ms) to deliver live inline syntax, security, and performance suggestions directly in your terminal.

saleha watch-ai .
