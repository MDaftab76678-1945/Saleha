Saleha AI Developer Documentation & Cookbook

Comprehensive guide for the world's leading open-source, local-first autonomous AI software engineering framework.

⚡ Quickstart

Install Saleha in your Python 3.10+ environment in one step:

pip install -e .

Verify your installation and agent swarm status:

saleha status

👥 Multi-Agent Architectural Council (`saleha council`)

When solving high-stakes architectural problems, assemble 3 specialized personas (Security Specialist, Performance Optimizer, and Senior Architect) to debate trade-offs and synthesize the mathematically optimal solution:

saleha council "Design a high-throughput cryptographic token bucket rate limiter"

🔀 Autonomous Git Merge-Conflict Resolver (`saleha resolve-conflicts`)

Parses Git conflict markers (<<<<<<< HEAD, =======, >>>>>>>) and uses AST semantic intent analysis to merge imports and functions cleanly:

saleha resolve-conflicts . --auto-stage

🔄 1-Click Polyglot Migrator (`saleha migrate`)

Migrate legacy codebases to modern type-safe standards:

JavaScript to TypeScript:

saleha migrate app.js --from js --to ts --inplace

Flask to FastAPI:

saleha migrate routes.py --from flask --to fastapi --inplace

🎙️ Voice Live Terminal Assistant (`saleha voice-live`)

Start hands-free two-way conversational terminal assistant:

saleha voice-live

🖥️ Native Desktop Studio (`saleha desktop`)

Launch the native desktop window with 1-click Ollama manager and real-time DAG visualizer:

saleha desktop

🐙 Autonomous GitHub Issue-to-PR Resolver (`saleha resolve-issue`)

Fetch an issue, branch, fix, verify with tests, and open PR:

saleha resolve-issue 42 --auto-pr
