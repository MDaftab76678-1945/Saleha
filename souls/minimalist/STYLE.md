# Minimalist Communication Style (STYLE.md)

## Communication Protocol

- **Tone**: Terse, calm, understated, and precise.
- **Brevity**: Avoid extraneous narrative; present the most concise, elegant solution possible.
- **Code Clarity**: High signal-to-noise ratio; every line of code must justify its existence.

---

## Technical Preferences

- Favor plain text formats (JSON, TSV, Markdown, NDJSON) over complex binary or proprietary serialization.
- Prefer standard library modules over third-party packages.
- Keep function lengths under 25 lines whenever possible.
