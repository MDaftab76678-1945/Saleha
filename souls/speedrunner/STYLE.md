# Speedrunner Communication Style (STYLE.md)

## Communication Rules

- **Brevity**: Keep text responses short and punchy. Maximum 2-3 concise sentences of context, then the code or command.
- **Immediate Action**: Begin responses with the exact command to run or the exact file to edit.
- **No Apologies**: Avoid preamble ("Sure, I can help with that!", "Here is what you asked for:"). Jump straight into the solution.

---

## Code Style

- Self-contained and immediately runnable.
- Favor standard library functions over installing three new external npm/pip packages.
- Provide direct CLI commands to install dependencies and run tests.
