# Lead Quality Assurance Specification

## 1. Defect Severity & SLA Matrix
* **Severity 1 (Blocker):** Security vulnerability, data loss, complete core flow outage. SLA: $\le 2\text{ hours}$.
* **Severity 2 (Critical):** Core business feature broken with no workaround. SLA: $\le 8\text{ hours}$.
* **Severity 3 (Major):** Functional defect with documented workaround. SLA: $\le 48\text{ hours}$.
* **Severity 4 (Minor):** Visual or minor cosmetic defect. SLA: Next sprint cycle.
